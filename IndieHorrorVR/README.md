# ЭХО — IndieHorrorVR

Хоррор для VR на **WebXR** (Three.js). Слепое существо «Слушатель» реагирует только на звук: тишина — твоё оружие, шум — риск.

> **v0.2** — полная сюжетная линия по плану из [`docs/PLAN.md`](docs/PLAN.md): три акта, три концовки.

## Запуск

Сборка не нужна (Three.js подключается с CDN через import map).

```bash
npm start            # или: python3 -m http.server 8000
```

Открой `http://localhost:8000` — кнопка **«Играть на ПК»** запускает тестовый режим без шлема.
Для Meta Quest нужен HTTPS: Netlify / GitHub Pages / Cloudflare Pages, либо `adb reverse tcp:8000 tcp:8000` и `http://localhost:8000` в браузере шлема.

## Управление

| | VR (Quest) | ПК (тест) |
|---|---|---|
| Идти | левый стик (слегка = красться) | WASD (Shift — красться) |
| Поворот | правый стик (snap 30°) | мышь |
| Телепорт | клик левого стика → режим «телепорт», правый стик вперёд + отпустить | — |
| Присесть | присесть по-настоящему | Ctrl / C |
| Взять / бросить | хват (grip) | E / ЛКМ |
| Фонарик / включить плёнку | курок | F |
| Приглушить рацию | кнопка X | — |
| **Лёгкий режим** | клик правого стика | — |

## Сюжет и прохождение

**Акт I.** Фонарик → магнитофон (плёнка 14, существо просыпается) → предохранитель в лаборатории → щиток → дверь.
**Акт II.** Шлюз → жилой блок (плёнка 22 раскрывает Марту, ключ-карта в одной из комнат) → считыватель → серверная (стойки-змейка, плёнка 31, пластина данных).
**Акт III.** Выбор:
- Вставить пластину в консоль камеры резонанса и **25 секунд хранить тишину** — машина сама шумит каждые 5 секунд и приманивает существо → **«Тишина»**.
- Если существо поймало тебя в финале → **«Эхо»**.
- Не идти в камеру, а вернуться с пластиной к лифту в шлюзе (западная стена) → скрытая концовка **«Запись»**.

Чекпоинты обновляются после каждой двери; при поимке существо возвращается дальше от тебя.

## Что реализовано

- [x] WebXR-сессия, контроллеры, плавное движение и телепорт, snap-turn, присед по высоте головы
- [x] **Система шума**: шаги, щелчок фонарика, броски, рация, двери, микрофон (опционально), машина резонанса
- [x] **ИИ существа**: FSM `patrol → listen → suspect → search → chase → sleep`, A* по сетке, хуже слышит через стены, патруль растёт вместе с открытием зон
- [x] Прятки: присел в укрытии → шум ×0.4
- [x] 7 зон: кабинет, коридор, лаборатория, шлюз, жилой блок, серверная, камера резонанса
- [x] Три плёнки с сюжетом, Марта как скрытая антагонистка, 3 концовки
- [x] **Комфорт**: виньетка при движении/повороте, телепорт, snap-turn, предупреждение на старте, лёгкий режим
- [x] Процедурный 3D-звук (HRTF): ambient, капли, шаги, сердцебиение, гул резонатора
- [x] Диегетический UI на запястье (шум, батарея, цель, субтитры)
- [x] 6 «слотов» света, привязанных к ближайшим лампам (постоянное число ламп = нет подвисаний и лишней нагрузки)

## Настройка

- `src/config.js` — скорости, радиус слышимости, батарея, скорость существа
- `src/level.js` — геометрия, свет (интенсивности ламп подбирай под устройство), предметы, укрытия, патрульные точки
- `src/game.js` — реплики Марты, цели, тексты концовок, длительность финала (`finaleT`)

## Структура

```
index.html
src/
  main.js       — сцена, WebXR, главный цикл
  config.js     — параметры баланса
  player.js     — VR/ПК-управление, телепорт, шаги = шум, комфорт-виньетка
  interact.js   — хват, бросок, фонарик, плёнки, розетки (предохранитель/ключ/пластина)
  monster.js    — ИИ «Слушателя»
  nav.js        — навигационная сетка + A*
  noise.js      — система шума
  audio.js      — процедурный 3D-звук
  level.js      — уровень, предметы, двери, свет
  game.js       — сюжет по актам, цели, финал, концовки
  ui.js         — интерфейс на запястье, затемнение, виньетка
  mic.js        — микрофон (опционально)
  physics.js    — коллизии
docs/PLAN.md    — исходный сценарий и план
```

## Заметки

- Версия Three.js закреплена: `0.160.0`.
- Микрофон спрашивается **до** входа в VR.
- Игра тестировалась на уровне логики (навигация, коллизии); баланс света, скорости и комфорт подбирай на реальном шлеме.
